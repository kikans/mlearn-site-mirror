# mLearn Site Mirror

Read-only mirror of https://mlearn.kikan.net for regions where Cloudflare is
slow or blocked, served via GitHub Pages at https://ru.mlearn.kikan.net.

Sign-in, registration, and the cloud dashboard are replaced with a notice:
the cloud API (mlearn-cloud.kikan.net) runs on Cloudflare and cannot be
mirrored. Downloads point at GitHub Releases and work fully.

Rebuilt from the mlearn-website repo with `npm run mirror:site`.
