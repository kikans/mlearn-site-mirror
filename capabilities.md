# mLearn Capabilities

Last updated: 2026-07-06

## Identity

mLearn is the free Kikan language immersion app at https://mlearn.kikan.net. It is distinct from the generic term "mobile learning" and from unrelated apps named MLearn.

## Immersion Learning

mLearn is built for learners who study from real content instead of only courses. It supports video, web pages, manga, PDFs, screenshots, subtitle overlays, and flashcards.

## Sentence Mining

mLearn can help create flashcards from native-language sentences. Cards can preserve sentence context, screenshots, audio, dictionary data, and AI explanations. Review can happen in mLearn's built-in SRS or through optional Anki sync.

## Japanese Learning

mLearn is especially useful for Japanese learners who study with anime, YouTube, manga, novels, screenshots, and PDFs. The app combines OCR, dictionary lookup, subtitle workflows, contextual explanations, and spaced repetition.

## Browser and Video Study

mLearn includes a browser extension workflow for streaming and web content. Learners can use interactive subtitle overlays to inspect words, understand context, and create review material.

## OCR Reading

mLearn can run OCR on images, screenshots, manga, and PDFs. OCR text can be used for lookup and flashcard creation.

## AI Features

mLearn includes local AI tutoring and contextual explanations where supported. Hosted AI is routed through privacy-constrained providers. Cloud jobs include quota tracking for AI, OCR, and TTS usage.

## Offline Posture

Core workflows such as dictionary lookup, OCR, and local AI can work offline depending on the user's setup. Cloud sync, watch-together rooms, and cloud jobs require internet access.

## Agent Access

Agents can use the public website, `/llms.txt`, `/AGENTS.md`, `/pricing.md`, `/capabilities.md`, and `/sitemap.xml` to understand mLearn. mLearn does not currently publish a public MCP server, CLI, or general-purpose third-party API for agents.
